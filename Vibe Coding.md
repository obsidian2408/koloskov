Ещё немного личного рейтинга по ИИ.

Пару месяцев тестировал все доступные тулзы для создания React приложения с NodeJS.

Задача была спарсить несколько сотен записей из Obsidian, собрать свой блог на React + TailwindCSS + SchadcnUI с рендером всего на сервере с NextJS **⟶** Настроить деполой на GitHub и по коммиту настроить экшны с выкладкой на YandexCloud с привязанным кириллическим доменом (что оказалось еще той задачей).

  Рейтинг туллзов:
1. Claude Code — бесспорный лидер 100%, но собака дорогой;
2. GeminiCL — хорош, но отстает от лидера по ряду функций;
3. Codex от OpenAI — приятно удивил;
4. Cursor — пузырь;
5. Windsurf — туда же.
  
Основными мои инструментом стал Warp https://www.warp.dev/ с подпиской (в пакете идет пачка моделей с динамическим переключением + агентский режим [еще не распробовал])

Ключевой инсайт по UI: 
- https://ui.shadcn.com/ — будет явно основной дизайн системой глобального Веба;
- https://v0.app — снизит вход в генерируемый UI и еще больше укрепить позиции shadcn;
- https://vercel.com — эталонный пример того как сделать DevOps доступным для широких масс.

И все это сейчас одна компания!
